87 tabs. Not a round number, because nobody with 87 tabs open counted them on purpose. It grew one tab at a time. A few tabs are real work, docs and dashboards that stay open all day. A dozen are articles I started and meant to finish. Some are videos saved for later, recipes, shopping pages, and rabbit holes that started with one search and ended somewhere I cannot explain. The rest are the "I will get back to this" tabs, and I never do, but I cannot close them either, because what if that one turns out to be important. That is 87 tabs: a chaotic, curious life, lived one open tab at a time.
